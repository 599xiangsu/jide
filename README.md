## 安装步骤

1. 手机上打开上面的下载链接
2. 点击下载好的 `.apk` 文件 → 系统提示「不允许安装未知来源应用」→ 按提示允许后继续
3. 打开 App，在引导页选择提醒方式
4. **重要**：允许通知权限，并保持设置里「强制闹钟 → 像手机自带闹钟一样叫醒」打开（默认就是开的）
5. **安卓 14 及以上**：还需要在系统里允许「全屏通知」，否则到点只会响一声，屏幕不会自己亮。
   设置页的「后台提醒自检」会检测这一项，未允许时会显示红字并给出「允许全屏唤醒」按钮，点一下就能过去打开

> 第 4、5 步不做的话，提醒会明显变弱，甚至只有打开 App 的时候才提醒你。

## 国内手机请再设置一步

小米 / 华为 / OPPO / vivo / 荣耀等系统会主动清理后台应用，需要在系统设置里放行，否则锁屏一段时间后提醒会失效：

| 品牌 | 位置 |
| --- | --- |
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → 记得 → **自启动**打开、**省电策略**选「无限制」 |
| 华为 / 荣耀 | 设置 → 应用 → 应用启动管理 → 记得 → 改为**手动管理**，三个开关全开 |
| OPPO / 一加 / realme | 设置 → 应用管理 → 记得 → 耗电管理 → **允许后台运行**、允许自启动 |
| vivo / iQOO | 设置 → 电池 → 后台高耗电 → 允许「记得」 |
| 原生 Android | 设置 → 应用 → 记得 → 电池 → **不受限制** |

App 里的「设置 → 后台提醒自检」可以直接看到当前状态（通知权限 / 全屏唤醒 / 精确闹钟 / 后台不被冻结 / 已排入系统），还有一个「10 秒后测试后台提醒」按钮：点完马上按 Home 键，10 秒后屏幕会自己亮起来。

## 关于权限

| 权限 | 用来做什么 |
| --- | --- |
| 通知 | 到点提醒你 |
| 闹钟和提醒 | 用系统闹钟级排期，让提醒准时送达、不被系统延后 |
| 全屏通知（安卓 14+） | 到点自动点亮屏幕、在锁屏上弹出提醒页，像手机自带闹钟一样 |

| 开机自启 | 手机重启后恢复已排好的提醒 |

## 两种提醒模式的取舍

设置页的「强制闹钟」开关默认打开：

- **打开**：到点由系统闹钟通道唤醒，屏幕自动点亮、锁屏之上直接弹出提醒页；走的是「闹钟」音量通道，所以**手机媒体音量为 0 时仍然会响**。代价是后台响的声音是系统闹钟铃声，不能用 App 里选的自定义音色（前台响铃仍然是自定义音色）。
- **关闭**：回到普通通知模式，不再亮屏。媒体音量为 0 就不响了，App 被系统清掉也可能收不到。

这是「强制」与「自定义后台音色」之间只能二选一的地方，默认选了强制。

### 一个使用提示（不是 bug）

**不要**在系统设置的「应用信息」里点「强行停止」。安卓规定：被强行停止的应用，
在你自己手动再次打开它之前，不再接收任何闹钟和广播 —— 这是系统行为，还会让你以为提醒坏了。

要让它彻底停止提醒，请用 App 里「设置 → 强制闹钟」那个开关。
